# Zahav Meeting OS

Sistema comercial da Zahav Digital para transformar reuniões em decisões confirmadas, propostas e planos de implantação com IA.

## Fluxo principal

Reunião → fatos extraídos → decisões confirmadas → fechamento → proposta → aprovação → implantação.

## Produto

- Dashboard executivo
- Clientes
- Reuniões guiadas por playbook
- Memória da reunião com origem/status
- Copiloto IA
- Fechamento personalizado
- Propostas versionadas
- Aprovação
- Implantação e checklists

## Stack inicial

- Next.js
- TypeScript
- Tailwind CSS
- Arquitetura preparada para Supabase, áudio/transcrição e LLM
